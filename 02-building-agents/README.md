# 02 · Building agents

How agentic applications work under the hood, and how to build them with [LangGraph](langgraph-basics.md), a widely used open-source framework that works with any model provider.

**You'll be able to:** explain the agent loop, design safe tools, build a LangGraph graph with checkpoints and human approval, pick a multi-agent pattern, and argue for a simpler design when an agent isn't needed.
