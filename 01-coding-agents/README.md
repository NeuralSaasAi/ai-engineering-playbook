# 01 · Coding agents

By 2027, working with a coding agent is a baseline skill, like using Git. This module teaches how agents work, how to give them the right context, and how to use them without shipping bugs or causing incidents.

You still need to be able to code. The agent writes faster than you; you decide whether what it wrote is right.

**You'll be able to:** set up an agent on a real project, write an `AGENTS.md` and a skill, connect an MCP server safely, and follow a spec-to-review workflow.
