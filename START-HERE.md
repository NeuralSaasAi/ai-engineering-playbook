## What you need

- **Time:** about 8 to 10 hours a week for 90 days covers everything. See the [90-day plan](09-careers-2027/90-day-plan.md).
- **Skills:** basic Python (functions, lists, dictionaries, installing packages). You don't need machine learning or maths beyond school level.
- **Tools:** a laptop with Python 3.12+, [uv](https://docs.astral.sh/uv/getting-started/installation/), and Git. Docker is optional (only for P5).
- **Money:** none. Every project's tests run offline. A free [Gemini API key](https://aistudio.google.com/apikey) lets you try real models, and an entry-level coding-agent plan (around $20 a month, or a free tier) is enough for module 01.
